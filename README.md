## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/harshdev9626/Python-Exp.git
```

### 2. Navigate to the project directory

```bash
cd Python-Exp
```

### 3. Install Python

Download and install Python from the official website:

https://www.python.org/downloads/

Verify the installation:

```bash
python --version
```

### 4. Run an experiment

Open the required experiment folder, locate its Python file, and run:

```bash
python filename.py
```

Replace `filename.py` with the name of the Python program you want to execute.

**Note:** Some experiments may require additional Python libraries. Install them according to the requirements of the respective program.
